# تحديث الحساب وتثبيت التطبيق

## Supabase — خطوة واحدة مطلوبة

من SQL Editor افتحي استعلاماً جديداً وانسخي كامل ملف `supabase/migrations/202609180005_self_service_settings.sql` ثم ملف `supabase/migrations/202609180006_dress_variants.sql`، وشغّلي كل ملف مرة واحدة بالترتيب. لا تعيدي تشغيل الملفات الأربعة السابقة. الملف 006 يضيف دالة لحفظ المقاسات والكميات كقطع مستقلة قابلة للحجز؛ لا يضيف جداول أو أعمدة ولا يغير بيانات الحجوزات.

الملف مجهز محلياً؛ لم يُطبّق تلقائياً على مشروع Supabase المستضاف. يحتاج حفظ إعدادات المعرض إلى تطبيقه.

## تعديل معلومات الحساب

من إعدادات المتجر يمكن تعديل اسم المعرض واسم صاحبه والشعار وهاتف التواصل وكلمة المرور. تغيير بريد الدخول يحتاج كلمة المرور الحالية وتأكيد رسائل البريد؛ يُخزّن البريد في Supabase Auth وليس في جدول المعارض.

لتغيير البريد على الموقع المنشور: اضبطي Authentication → URL Configuration → Site URL على رابط الموقع، وأضيفي `https://YOUR-DOMAIN/auth/callback` ضمن Redirect URLs. للتطوير أضيفي `http://localhost:3000/auth/callback`. أبقي Secure email change مفعّلاً لتأكيد البريد القديم والجديد. يلزم ضبط SMTP لإرسال الرسائل إلى مستخدمين حقيقيين خارج القيود التجريبية لخدمة البريد الافتراضية. لم يُختبر تسليم الرسائل فعلياً في هذا التحديث.

## التثبيت

ارفعوا الموقع على HTTPS. من زر «تثبيت التطبيق» يظهر طلب التثبيت في المتصفحات الداعمة، أو خطوات الإضافة اليدوية. على iPhone افتحي الموقع في Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية. لا يلزم متجر تطبيقات.

للتطبيق أيقونة ومظهر نافذة مستقلة. بيانات المعرض تحتاج الإنترنت؛ عند انقطاعه تظهر صفحة توضيحية. لا تُخزّن بيانات العملاء أو الجلسات في كاش الخدمة. لا يحتاج التثبيت إلى تعديل Supabase.
